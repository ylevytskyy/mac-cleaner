# Додаткові кеші редакторів

## Мета
Збільшити обсяг доступного очищення в категорії `browsers`.
Додати `CachedExtensionVSIXs` для VS Code, VS Code Insiders, Cursor,
Windsurf, а також підтримку кешів Devin і Devin - Next.

## Терміни
Кеш розширень — завантажені архіви `CachedExtensionVSIXs`, окремі від
встановлених розширень. Кеш редактора — лише явно дозволені підкаталоги.
Джерело: https://github.com/microsoft/vscode/blob/main/src/vs/platform/environment/common/environmentService.ts
і https://github.com/microsoft/vscode/blob/main/src/vs/platform/extensionManagement/node/extensionDownloader.ts .

## Definition of done
Запуск CLI на тимчасових даних показує нові цілі у скануванні та попередньому
перегляді, видаляє їх після підтвердження, зберігає сусідні дані й пропускає
запущені редактори. Синтаксична перевірка та реальний `--dry-run` завершуються.

## Open questions
Немає.

## Deliberately does NOT do
Не видаляє встановлені розширення, налаштування, розмови, історію, облікові
дані чи проєкти. Для нових редакторів не очищає `Service Worker`.
Не змінює прапорці CLI, наявні цілі браузерів або правила підтвердження.
Не запускає справжнє очищення користувацького Mac.

## Alternatives considered
Окрема категорія для кожного редактора збільшила б інтерфейс без потреби:
наявний механізм Electron уже має сканування, підтвердження та перевірку процесу.
Рекурсивний пошук кешів відхилено: цілі мають бути явно дозволені.

## Next implementation step
Перевірити відсутнє очищення VSIX через CLI на тимчасових даних, потім
розширити дозволені підкаталоги лише для редакторів.
